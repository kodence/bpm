# BP Tracker

A small Windows desktop app for logging daily blood pressure readings.

## Run it

Double-click **`BP Tracker.bat`** in this folder.

Or from a terminal:

```
npm start
```

## What it does

- Log a reading: date and time are pre-filled (click "now" to reset them). Type systolic, diastolic, optional pulse and a note, press Enter. After the third digit of systolic or diastolic the cursor jumps to the next field on its own.
- The category (Normal, Elevated, High, Crisis) shows as you type. Normal is up to 135/89 by default.

## Thresholds

Click **⚙ Settings** to change the limits. They are stored in an editable file:

```
%APPDATA%\BP Tracker\preferences.json
```

```json
{
  "normalMax":   { "sys": 135, "dia": 89 },
  "highFrom":    { "sys": 140, "dia": 90 },
  "crisisAbove": { "sys": 180, "dia": 120 }
}
```

Readings at or below `normalMax` are Normal, at or above `highFrom` are High, above `crisisAbove` are Crisis, and anything in between is Elevated. The dashed lines on the chart mark the normal limit. Restart the app after editing the file by hand.
- See your last reading, 7-day and 30-day averages, and a trend chart for 7 / 30 / 90 days or all time. The averages cover the days ending at your most recent reading.
- Edit or delete any reading from the history table. Search by date or note.
- Export everything to CSV (opens in Excel), or import a CSV with `Date,Time,Systolic,Diastolic,Pulse,Notes` columns.

## Where the data lives

Readings are saved in a single JSON file in your Windows profile:

```
%APPDATA%\BP Tracker\bp-data.json
```

Click **Data folder** in the app to open it. Back that file up, or use Export CSV.

To keep the readings somewhere else (OneDrive, Dropbox, a USB drive), open **⚙ Settings** and use **Change…** under Data folder. Your current readings are copied to the new folder, and the choice is saved as `dataFolder` in `preferences.json`:

```json
{
  "dataFolder": "D:\\OneDrive\\Health"
}
```

**Use default** switches back to the app's own folder. If the chosen folder is unavailable when the app starts (for example a USB drive is unplugged), the app warns you and uses the default folder until it is back.

## Build a standalone .exe

```
npm run build
```

This produces `dist\BP Tracker-win32-x64\BP Tracker.exe`. Copy that folder anywhere (or make a shortcut to the exe) and run it without Node installed.

## Rebuild the icon

`assets/icon.ico` is generated by `python assets/make_icon.py` (no extra packages needed).

This app is a personal log, not medical advice.
